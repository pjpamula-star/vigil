What changed from v1

• The headline answers your real question: can I close the lid? It reads like an iPhone Live Activity, understood in a second.

• Each session is one human sentence, not a command name.

• Heat, battery and phone are hidden when fine. They show up only when something's wrong.

• One color per meaning: blue for working, orange for needs you, green for done, red for danger.

How the short summaries work

1 · Headline (≤ 20 words)What Claude got done and where it's at, in plain English. Written by Claude's fastest model (Haiku) in about 8 seconds, from the session's own log.
2 · Fact chipsFiles changed, tests, commits, deploys and errors. These are read straight from the log, never guessed, so the numbers are always exact.
3 · TimelineOne line per real step, newest first. Routine file reads are hidden, and anything with an outcome is kept.
Never left outQuestions Claude asked you · errors and failed tests · installs, deletions, pushes and deploys · anything Claude said it couldn't do · usage limits.
